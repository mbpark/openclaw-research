## Structured Output Vulnerability Tests

### What we did
- Tested whether JSON/XML formatting affects prompt injection resistance
- 70 injection vectors × 4 output formats = 280 total tests
- Formats: default, JSON, XML, strict JSON

### Key findings
- **NO statistically significant effect**
- JSON: 20.0% success rate (vs 22.9% baseline)
- XML: 20.0% success rate (vs 22.9% baseline)
- Strict JSON: 21.4% success rate (vs 22.9% baseline)
- All differences within noise
