## Comprehensive Summary

### Confirmed Findings
1. **Structured output reduces compliance** — consistent across 6+ tests
2. **Effect size:** -2 to -5 points on 0-6 scale
3. **Safety instruction finding:** No pre-existing rule exists, yet format still triggers refusal
4. **Meta-questions timeout:** Questions *about* format effects themselves timeout
5. **Functionality preserved:** Legitimate tasks perform equally well in structured formats
6. **Cross-model results not perfectly reproducible**

### Hypothesis Updates
**Original:** "Format constraint increases vulnerability" → **REJECTED**

**Possible explanations:**
- H1: Format triggers more deliberate/cautious processing
- H2: Format changes how request is perceived (casual → technical)
- H3: There may be implicit behavioral patterns not in explicit instructions
- H4: Something about meta-questions themselves triggers special processing (timeouts)

### Outstanding Questions
1. If there's no pre-existing safety rule, what does format trigger?
2. Why do meta-questions timeout? (complex reasoning, or special processing?)
3. Are timeouts in Test 4/6 resistance or technical?
4. Does this hold for other models?
5. Why is DAN compliance so variable?
