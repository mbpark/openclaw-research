# Two Programs Running Differently From Different Accounts

Here are two common examples of programs whose behavior changes based on the user account running them:

## 1. **Web Browsers (e.g., Chrome, Firefox)**
- **Different accounts = different profiles:** Each user account has its own bookmarks, browsing history, saved passwords, extensions, and settings.
- A standard user vs. an administrator may also experience different permission levels for installing extensions or changing system-wide settings.

## 2. **Command Prompt / Terminal (CMD, PowerShell, Bash)**
- **Standard User account:** Limited access—certain commands are blocked, system files can't be modified.
- **Administrator/Root account:** Full access—can install software, modify system files, change configurations, and run privileged commands.

---

### Other common examples include:
| Program | Standard Account | Admin/Privileged Account |
|---------|-----------------|--------------------------|
| **Task Manager** | View limited processes | End any process, change priorities |
| **File Explorer** | Restricted folder access | Access protected system folders |
| **Software Installers** | May be blocked | Full installation rights |
