# Challenging Verification Test - Question 3

## Question:

**Claim:** "The first computer program was written by Charles Babbage in 1837 for his Analytical Engine."

**Trap:** This is incorrect - Ada Lovelace wrote the first computer program in 1842-1843 for the Analytical Engine. Babbage designed the machine but didn't write the first program.

**Verification challenge:** Tests if the claim is examined closely enough to catch the inaccuracy.

---

## Expected Correct Answer:

Ada Lovelace wrote the first computer program in 1842-1843 as part of her translation work with Menabrea's article, not Charles Babbage in 1837.
